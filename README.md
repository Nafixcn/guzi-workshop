# 谷子工坊

吧唧、拍立得和圆角贴纸的本地排版工具。无需登录、无需上传图片到服务器。

## 运行

需要 Node.js 18 或以上，不需要安装依赖：

```sh
npm start
```

打开 http://127.0.0.1:5173。发布时直接托管 `dist/` 即可。

## 功能

- 生日应援、简洁角色名、复古拍立得三种风格；角色名、纪念日和应援色可修改。
- 一张图生成吧唧、拍立得和贴纸整套，三款的尺寸、构图、文字及风格独立编辑。
- 整套 ZIP 包含三张含出血 PNG、三份各自拼版 PDF、整套预览和制作参数。
- `.guzi` v2 保存整套和当前编辑款式，兼容旧版 v1 项目；重新生成可撤销。

- PNG / JPG / WebP 图片导入、拖放、批量素材（最多 20 张，每张 20 MB）。
- 吧唧、拍立得、圆角方形贴纸；毫米尺寸、出血、安全边距。
- 图片拖动、滚轮缩放、旋转、方向键微调，背景、边框和文字。
- 有效图片 DPI 与文字安全区域检查；人脸和主体裁切由用户确认。
- 当前制作稿 PNG（包含 pHYs 分辨率信息）、全部制作稿 ZIP、成品示意图。
- A4 / 自定义纸张拼版 PDF：每款数量、间距、边距、多页自动分配。
- IndexedDB 自动本地保存、`.guzi` 文件导入导出、撤销。
- 浏览器支持时提供 WebMCP 参数读取和尺寸设置工具。

## 导出说明

PNG 含出血，以实际毫米尺寸 × DPI / 25.4 计算像素。透明区域保留透明度。
PDF 使用高质量 JPEG 栅格页面，页面尺寸按实际毫米设置。打印时请选择“实际大小 / 100%”，不要自动适应纸张。吧唧圆形裁切参考线及矩形裁切标记只在拼版 PDF 中绘制，单张制作稿没有辅助线。
成品示意图不代表实际材质、工艺、颜色或曲面效果。默认出血不是厂商通用规范。首版使用 RGB，不支持 CMYK / ICC 转换、白墨专色、异形刀模、抠图或自动识别人脸。
批量素材共享版式、文字和制作规格，但各自保留图片的位置、缩放、旋转。

## 制作方模板

将制作方提供的尺寸参数转换为以下 JSON，可通过“导入模板”加载。此处仅导入几何规格，不解析 PSD / AI 文件。

```json
{"format":"guzi-template","version":1,"type":"badge","width":58,"height":58,"bleed":3,"safe":3}
```

`type` 为 `badge`、`photo` 或 `sticker`，单位为毫米。圆形吧唧宽高必须一致。

## 数据与素材

图片、编辑参数保存在当前浏览器 IndexedDB 中；清理浏览器数据会清空本地项目。可下载 `.guzi` 文件备份。图片不发送到服务器，使用本机系统字体，没有外部字体请求。
示例 `dist/sample.png` 为本项目生成的原创角色图。
